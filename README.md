# Personal Portfolio Website

## 📌 Overview

This is a **personal portfolio website** created using **HTML and CSS**.
The website introduces me, showcases my skills, projects, and provides a way for people to contact me.

This portfolio is designed with a **modern dark UI**, clean layout, and responsive sections.

## 🎯 Features

* Clean and modern portfolio design
* Navigation bar with multiple sections
* Introduction / Hero section
* Skills section
* Projects showcase section
* Contact section
* Responsive layout using CSS
